**正直なチェック - 今日実際に動くもの：** 画面のルールは C++17 で書かれ、コンピューター上でテスト済みです。安全な既定値を持つ設定ファイル、すべての移動とスピンドル命令が通る関門（画面での確認、ハードウェア停止のラッチ、有効なリンク）、8 言語の音声命令と通知、各画面の文言です。LVGL 画面を持つ ESP-IDF ファームウェアは Guition JC8012P4A1C モジュール向けに書かれていますが、**ビルド、書き込み、モジュール上での実行はまだしていません**。サーバーやマシンへのリンクもまだなく、マシンには何も接続していません。

---

> **安全とセキュリティの状況：** これは安全システムではありません。人とマシンを守る停止は、ドライブを自ら遮断するハードウェアボタンで、この画面とは別に配線されます。画面はそれを読み取って表示するだけで、押されている間や未確認の間は何も動かしません。移動やスピンドルの命令は画面での確認を求め、音声命令は常に確認を求め、音声命令は操作者が有効にするまでオフです。全体の経路を実機で試すまで、この画面でマシンを動かさないでください。このプロジェクトは独立しており、Bungard Elektronik や Guition が作成・承認・サポートするものではありません。製品名は対象のマシンとモジュールを示すためにのみ現れます。

## 🎯 概要

* **関門**：タッチでも音声でも、すべての移動とスピンドル命令が 1 か所を通り、そこで実行・確認要求・理由付きの拒否が決まります。停止は常に通ります。
* **設定ファイル** `hmi.cfg`：調整するすべての値（言語、明るさ、サーバー、安全スイッチ、音声）は専用パーティションの 1 ファイルの 1 行で、コード内の数値ではありません。範囲外の値は報告され、安全な既定値が残ります。
* **音声**：音声通知（ジョブ完了、工具交換、エラー、リンク切断、ハードウェア停止）と、8 言語の短い固定の音声命令リスト。停止だけの命令は文中でも認識され、移動や回転の命令は全文で言う必要があり、常に確認を求めます。
* **画面**：マシン（ジョグ、原点、スピンドル、開始、停止）、ジョブ、ビューア、サーバーのマシンとステーション、設定を、デスクトップ版と同じ順序・名前で並べます。停止ボタンは常に最上部にあります。
* **モジュール**：Guition JC8012P4A1C（32 MB 外部 RAM の ESP32-P4、10.1 インチ 800x1280 MIPI-DSI タッチディスプレイ、Wi-Fi 用 ESP32-C6、スピーカーアンプ付き ES8311 コーデック、ES7210 マイク入力）。この機体のパネルは新タイプです。

## 🧩 EH3D での役割

EH3D-NODE-BUNGARD-HMI は Bungard CCD マシンの操作者専用の画面で、マシン横の PC の代わりになります。EH3D-DRILLPRO や EH3D-ROUTEPRO と同様に、EH3D-SERVER または EH3D-NODE-BUNGARD（マシンのシリアルポートのノード）を通じてマシンを動かす想定です。そのリンクはまだ書かれていません。

## ✨ 機能

* **忘れられない停止：** 停止ボタンは常に最上部にあり常に有効です。ハードウェア停止はラッチされ、ボタンを離した状態で画面で確認したときだけ解除されます。
* **動かす前の確認：** 移動やスピンドル命令は実行内容を表示し、制限時間内のタッチを待ちます。新しい要求やリンク切断で破棄されます。
* **音声も含めた 8 言語：** 英語、スペイン語、イタリア語、ドイツ語、フランス語、ポルトガル（ポルトガル）語、中国語、日本語で、画面、音声通知、音声命令に対応します。
* **既定で安全：** すべての安全スイッチは設定で切り替えられ、保守的な位置から始まります。音声命令オフ、音声による確認オフ、確認オン、ハードウェア停止必須。

## 🔒 セキュリティと安全

| 脅威 | 防御 |
|---|---|
| タッチや音声命令で誤ってマシンが動く | 移動は画面で制限時間付きの確認を求めます。音声命令は常に確認を求め、音声の「はい」は設定 `voice_confirm` がオン（既定ではオフ）のときだけ確認になります |
| ハードウェア停止が押されているのに画面が動かす | ハードウェア停止はラッチです。押されている間、または離しても画面で確認していない間は、すべての移動とスピンドル命令が拒否され、待機中のものは破棄されます。確認待ちの間に停止が押されると取り消されます |
| 準備ができていないマシン | リンクが有効でない、ハードウェア停止入力が配線されていない（`hw_stop_required`、既定でオン）、またはスピンドル上限が 0 のときは何も動きません |
| 話した言葉が命令と誤認される | 命令は言語ごとの短い固定リストから来ており、自由文ではありません。命令を含むだけの語（`stopwatch`）は命令ではなく、音声命令は操作者が有効にするまでオフです |
| 設定の打ち間違い | 範囲外の値や未知のキーは報告され、安全な既定値が残ります。間違いでスイッチが開くことはありません |
| ファームウェアやリポジトリ内の秘密 | 秘密はコンパイルされません。トークンは専用パーティションの設定で、表示もログ出力もされません |

**防御していないもの：** 画面は安全装置ではなく、マシンのドライブを遮断できません。それはハードウェア停止が単独で行わなければなりません。サーバーへのリンクはまだなく、現時点で画面はマシンを一切動かせません。音声認識はテストではテキストとして動かしており、実際のマイク経路（エコー除去、雑音、訛り）は試していません。モジュールを手にした人は設定ファイルを変更できます。

## ⚙️ 設定

調整するものはすべて `hmi.cfg` の 1 行です（`hmi.cfg.example` を `config` パーティションにコピー）。範囲外の値はログに報告され、既定値が残ります。以下は既定値で、安全に関する既定値はすべて保守的です。

| 設定 | 既定 | 範囲 | 内容 |
|---|---|---|---|
| `language` | `en` | `en es it de fr pt zh ja` | 画面と音声の言語 |
| `confirm_moves` | on | on / off | 移動に確認を求める：試験台でのみオフに |
| `confirm_timeout_ms` | 8000 | 1000 - 60000 | 確認を待つ時間 |
| `jog_max_mm` | 20 | 1 - 200 | 画面が送る 1 回の最長ジョグ |
| `spindle_max_rpm` | 24000 | 0 - 65535 | 要求する最高スピンドル回転数（0：スピンドルを始動しない） |
| `hw_stop_required` | on | on / off | ハードウェア停止入力が配線され解除されているときだけマシンを制御 |
| `voice_orders` | off | on / off | 音声命令を受け付ける |
| `voice_confirm` | off | on / off | 音声の「はい」を移動の確認として受け付ける |
| `token` | none | 8 - 64 characters | サーバーのアクセストークン。書き込み専用で、表示もログ出力もされません |

## 🚀 クイックスタート

ホストテストには C++17 コンパイラーと CMake、ファームウェアには ESP-IDF 5.5.5（モジュールの ESP32-P4 ターゲット）が必要です。

```bash
build.bat            # the host tests (Windows)  -  ./build.sh on Linux
python -I tools/ci_validate.py
```

ファームウェアはまだビルドしていません。ビルドすると `idf.py set-target esp32p4 && idf.py build` でイメージができ、`config` というパーティションに `hmi.cfg` が入ります。

## 🩺 トラブルシューティング

| 症状 | 対処 |
|---|---|
| 何も動かず、画面にハードウェア停止が押されている/未確認と表示される | ボタンを離してから、画面の確認ボタンを押してください。離した停止は自動では解除されません。 |
| 画面にマシンが有効でないと表示される | このバージョンにはまだマシンへのリンクがなく、リンクが有効にするまで関門はすべての移動を拒否します。 |
| 画面にハードウェア停止入力が配線されていないと表示される | 停止ボタンを menuconfig で設定したピン（`HMI_HW_STOP_GPIO`）に配線するか、試験台でのみ `hw_stop_required` をオフにします。 |
| 音声命令が何も起こさない | 音声命令は既定でオフです。`voice_orders = on` に設定してください。移動や回転の命令は、`voice_confirm` がオンでない限り画面でのタッチを求めます。 |

## 🗺️ ロードマップと既知の制限

**現時点の既知の制限**

* モジュール上では何も動いていません。ファームウェアはビルド・書き込み・試用をしておらず、必要なボードサポートパッケージはこのモジュール用に変更が要るかもしれません。
* EH3D-SERVER やマシンのノードへのリンクはまだなく、画面はマシンを動かせません。ビューア、ジョブ、マシンとステーション、設定のタブは空のページです。
* ハードウェア停止のピンとタッチコントローラーはまだ確定しておらず、本体の回路図で確認する必要があります。
* 音声認識器とスピーカーはまだファームウェアに入っておらず、命令と通知はテキストとしてテストしています。
* デスクトップ版のロジック（フォーマット、コントローラー、フリート）は再利用していません。画面はデスクトップ版に倣いますが、ルールは C++ で書き直しています。

**次にやること**

* ファームウェアをビルドしてモジュールを起動する：表示、タッチ、サウンド。
* EH3D-SERVER とノードへのリンクを書き、画面の他のタブを埋める。
* 音声認識器とスピーカーを加え、エコー除去とあわせて試す。
* 実際の停止ボタンを配線し、マシンでラッチを試す。

* README は 8 言語あります。文面の変更は 8 ファイルすべてで行い、2 つの図は `tools/make_architecture.py` と `tools/make_structure.py` が `docs/architecture.json` と `docs/structure.json` から描きます。
* 画面がマシンを動かせるようになる変更は、それを対象とする関門のテストと、ハードウェアで観察した内容のメモなしには行いません。
* 脆弱性は非公開で報告してください：[SECURITY.md](SECURITY.md)。質問、アイデア、報告：electrohobby3d@gmail.com（[SUPPORT.md](SUPPORT.md)）。
